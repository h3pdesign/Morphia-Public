# Morphia: Living Art — public website

Standalone GitHub Pages marketing site for Morphia: Living Art, modeled on the Liquid Record public website. This repository contains only public website content and selected App Store screenshots, not the app source.

Live site: https://h3pdesign.github.io/Morphia-Public/ (English) and https://h3pdesign.github.io/Morphia-Public/de/ (German)

## Hosting

GitHub Pages serves the `main` branch root. `.nojekyll` enables direct static serving. There are no JavaScript dependencies, trackers, cookies, external fonts, or third-party embeds.

## Preview

Run `python3 -m http.server 8080` in this folder, then open http://localhost:8080.

## App Store release

Morphia: Living Art is available for iPhone, with a companion Apple Watch app: https://apps.apple.com/app/morphia-living-art/id6833573410

The app is free to download, with an optional one-time Morphia Studio in-app purchase (€9.99 in Germany, verified against the App Store listing on November 14, 2026). Local prices may vary. Keep pricing, the list of what Studio unlocks, and legal links accurate when updating the site. English and German pages must stay in sync.

Screenshots are the framed App Store screenshots of version 1.2.0 (`assets/screenshots/en` and `assets/screenshots/de`), resized to 660 × 1434 WebP.
